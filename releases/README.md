# Oneline

## 一、项目概述

Oneline 是一个绿色版桌面游戏前端，用于把多个平台（FC、SFC、PS1 等）的 ROM 汇总到一张统一的游戏列表中。启动后可选择平台、搜索游戏、筛选收藏，单击模拟器标签或双击游戏行即可调用对应模拟器运行游戏；启动游戏时前端自动隐藏，模拟器退出后自动恢复。游戏名称可通过 `.lst` / `.glt` 映射表替换为中文名，窗口大小、列宽、平台配置与收藏记录保存在 exe 同目录的 `config.json` 中。




## 二、使用教程

**目录结构**

```
releases/
├── Oneline.exe   # 主程序，双击启动（无控制台窗口）
├── config.json   # 首次运行后自动生成，所有设置与收藏都保存在这里
└── lib/          # 运行库与图标资源，随程序一起提供，请勿删除或移动
```

`Oneline.exe` 必须与 `lib\` 放在同一目录才能启动；整个文件夹可以整体复制或移动到任意位置。程序只读写自己所在目录的 `config.json`，不会修改 ROM 或模拟器文件。



**启动与首次配置**

1. 双击 `Oneline.exe` 启动，首次运行会在 exe 旁生成默认 `config.json`，游戏列表初始为空。
2. 点击工具栏的 **导入设置**，在「新增平台」页填写平台信息：
   - **平台名称**：如「任天堂 FC」「PS1」；
   - **ROMS 目录**：存放 ROM 文件的文件夹，可用右侧「浏览…」选择；
   - **映射列表**（可选）：`.lst` / `.glt` / `.txt` 文件，把 ROM 文件名映射为显示名；
   - **仅显示列表中匹配的 ROM**：勾选后，未出现在映射列表中的 ROM 不显示；
   - **模拟器**：点击「+ 添加模拟器」，填写名称、选择可执行文件路径（`.exe` / `.bat` / `.cmd`），必要时修改运行指令模板。
3. 点击 **添加平台** 保存。切换到「平台管理」页可对已配置的平台进行编辑或删除（删除只删配置，不删 ROM 文件）。关闭对话框后列表会自动刷新。



**运行指令模板**

每个模拟器可自定义启动命令，默认模板为 `"{emulator}" "{rom}"`。可用的占位符如下：

| 占位符       | 含义                   |
| ------------ | ---------------------- |
| `{emulator}` | 模拟器可执行文件路径   |
| `{rom}`      | ROM 完整路径（含后缀） |
| `{romname}`  | ROM 文件名（含后缀）   |
| `{romstem}`  | ROM 文件名（不含后缀） |
| `{romdir}`   | ROM 所在目录           |

例如 `"{emulator}" -fullscreen "{rom}"` 表示全屏启动。相对路径以程序所在目录为基准，建议直接填写模拟器的绝对路径。



**游戏列表与启动**

| 操作                                        | 效果                                   |
| ------------------------------------------- | -------------------------------------- |
| 双击游戏行                                  | 用该平台配置的**第一个**模拟器启动游戏 |
| 单击「模拟器」列的彩色标签                  | 用标签对应的模拟器启动游戏             |
| 右键游戏行 →「启动游戏」                    | 配置多个模拟器时可在子菜单中选择       |
| 右键游戏行 →「添加到收藏」/「从收藏中移除」 | 收藏的游戏名称会标为红色               |

启动后前端窗口自动隐藏并转入后台监控；关闭模拟器后窗口自动恢复。表格三列分别为「游戏名称」（含平台图标）、「平台」、「模拟器」（彩色标签），整表只读，拖动表头边界可调整前两列宽度，关闭程序时自动保存。



**搜索与筛选**

- 在工具栏搜索框输入关键词，按游戏名或文件名实时过滤（输入有短暂防抖）。
- 点击工具栏的 **筛选** 按钮打开菜单：
  - **我的收藏**：只显示收藏的游戏；
  - **全部平台**：清除筛选，显示全部游戏；
  - 下方平台列表可多选，只显示勾选平台下的游戏；再次点击同一平台可取消。
- 状态栏显示当前数量：无筛选时为 `共 N 个游戏`，有搜索或筛选时为 `显示 N / M`。
- 点击工具栏 **刷新** 可重新扫描所有平台的 ROM 目录。



**映射列表格式（可选）**

`.lst` / `.glt` 文件每行用 Tab 分隔，**只取前两列**：第一列为 ROM 文件名（可不含后缀，大小写不敏感），第二列为显示名称；以 `//` 开头的行和空行会被忽略。文件编码自动识别（UTF-8 / GBK / Big5 / Shift-JIS 等），无法匹配到的 ROM 仍显示其文件名。例如：

```text
mario	超级马力欧
zelda	塞尔达传说
metroid	密特罗德
```



**配置与维护**

- 所有设置都保存在 `config.json`，可直接用文本编辑器查看或修改；修改前建议先关闭程序，否则退出时的自动保存会覆盖手动修改。
- 想换一台电脑使用时，把整个 `releases` 文件夹复制过去即可；只想迁移设置时复制 `config.json`。
- 找不到游戏时：确认「ROMS 目录」路径正确、ROM 文件未被隐藏，然后点击「刷新」；若勾选了「仅显示列表中匹配的 ROM」，请检查映射表是否包含该游戏。
- 无法启动游戏时：在「导入设置」中确认模拟器路径存在，且运行指令模板中的占位符拼写正确。
- 若修改了 `lib\` 中的内容导致程序异常，请从原始安装包重新解压该目录；`config.json` 可单独保留。
